# 用户 → 会话 → Key → 推理 → 计费生命周期审计

日期：2026-09-07。生产站点：`sub2api-worker-production.claude-code-best.workers.dev`。

## 发布与结论

已部署版本 `0.42.45`，Cloudflare Version ID `9c62902b-64be-4fa0-8584-d77ea9c3ae78`，代码提交 `16e79fddd`（生命周期修复 `9df97b3f1`，合并主仓库 `65c232be7` 的列表/兑换码修复）。代码位于隔离分支 `codex/user-lifecycle-audit`，未覆盖共享工作区中的其他未提交工作。

本轮由用户/会话、Key、推理/账务三个子代理分别审计并交叉复查，主代理统一集成、部署及线上验证。发现并修复了跨身份会话竞态、状态查询与展示不一致、精确过期时间丢失、请求标识不一致、失败流计费和仪表盘日期边界问题。真实上游调用仍有阻塞，不能宣称整个生产模型链路已完全恢复。

## 修复内容

| 生命周期环节 | 确认的问题和修复 |
| --- | --- |
| 用户禁用/恢复、密码重置 | 增加认证版本失效与会话撤销；用户恢复后旧会话不会重新有效；密码重置撤销关联恢复会话 |
| 浏览器切换用户 | 保留 UUID 身份；拒绝跨用户刷新结果，旧 401 不会在新用户身份下重放操作，旧 `/me` 200 不会覆盖新用户 |
| Key 列表 | 支持 active/inactive/expired/quota_exhausted 四种筛选；可用状态排除到期与耗尽，分页条件与展示一致 |
| Key 创建与编辑 | 传递用户指定的精确到期时间；只改名称不再重发旧的过去到期时间，保留秒和毫秒 |
| 请求跟踪与幂等账务 | 使用服务器生成的同一 UUID 关联响应、网关、用量及账务，避免不同层请求 ID 不一致 |
| 非流式失败 | 上游 HTTP 200 但返回无效 JSON 时返回 502，并释放预留，不作为成功扣费 |
| 流式失败 | error 后的 DONE 不覆盖失败；无输出且无有效 usage 不计费；部分输出失败按实际用量结算，并继续收集后续 usage 帧 |
| 仪表盘、逐 Key 用量 | 统计日期、小时桶与浏览器时区一致，覆盖夏令时和非整小时时区；前端批量统计请求携带时区 |
| 上游健康探测 | 超时预算从 4 秒改为有界 20 秒；慢响应恢复与真正超时/退避均有回归。此调整没有解决当前上游的真实超时 |

详细证据见 [用户与会话](lifecycle-users.md)、[Key](lifecycle-keys.md)、[推理与账务](lifecycle-billing.md)。

## 线上验证与边界

部署后用户资料、会话、Key、可用分组、订阅、用量及管理仪表盘等 23 个只读接口均返回 200。它证明这些接口可访问、响应结构正常，不证明每个历史统计数字均经过人工对账。

临时测试用户在线验证：

- 四种 Key 状态筛选均 200；此前 expired/quota_exhausted 为 400。
- 禁用用户后旧会话 401、Key 403；恢复用户后旧会话仍 401，重新登录成功。此前恢复用户会让旧会话重新 200。
- 删除 Key 后原密钥 401。
- Key 启停探针最初错误使用 `enabled`，该次 200 不纳入通过证据；最终按前端公开契约 `status` 重跑：创建成功，停用返回 inactive 且网关 401，启用返回 active 且网关 200，删除后 401，断言全部通过。
- 真实 `composer-2.5-fast` 非流式、256 token 上限请求返回 429 `Upstream account quota is exhausted`，请求 ID `9881cf9b-4bd0-4e01-88a5-eb1de7e79901`。测试用户注入的 5000 微美元余额仍为 5000，失败请求没有扣费。

线上邮件投递、第三方 OAuth 跳转、硬件 Passkey、真实支付及退款未进行实际操作；这些边界不在本轮线上通过声明内。生产注册策略保持原配置，注册使用本地浏览器验收。
